# Contributing to l2met-shuttle

## Governance Model

`l2met-shuttle` is published but not supported. It contains code and concepts
that may be useful to the open source community, but the project does not
solicit contributions or provide support commitments. Occasional maintenance
may occur at the maintainers' discretion.

## Issues and Pull Requests

Use [GitHub Issues](https://github.com/heroku/l2met-shuttle/issues) to report
bugs or discuss ideas. Pull requests should target the `master` branch and be
limited to a clear, well-tested change. Maintainers may not review or accept
contributions.

Before opening a pull request, run:

```sh
go test ./...
```

## Contributor License Agreement

To accept a pull request, Salesforce requires a signed [Salesforce Contributor
License Agreement](https://cla.salesforce.com/sign-cla). You only need to sign
the CLA once for Salesforce open source projects.
